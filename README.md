# AI搜索时代 × 健身瑜伽行业方向性研究（双报告去水印汇编）

本仓库为静态网页项目。页面基于两份去水印原版报告，结合 2025–2026 健身瑜伽行业动态，输出方向性结论。

## 目录结构

```
.
└── index.html                  # 主页面（结论 + 行业动态 + 报告收录）
```

两份去水印PDF（CBNData·37页、魔镜洞察·95页）体积较大，页面内通过在线链接查看与下载，未纳入仓库；全文TXT归档随交付文件本地提供。

## 本地查看

直接用浏览器打开 `index.html` 即可；PDF 在线查看依赖浏览器内置阅读器，无法显示时点「下载PDF」或在新标签打开链接。图表使用 ECharts（jsDelivr CDN），需联网加载。
